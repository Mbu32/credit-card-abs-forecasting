# Predicting Performance of Credit Cards ABS

This project applies time series forecasting to predict delinquency and charge-off rates on credit card asset-backed-securities (ABS). Using macroeconomic and credit performance data sourced from the Federal Reserve Economic Data [FRED](https://fred.stlouisfed.org/), I'll compare classical statistical models (SARIMAX) with deep learning approaches (LSTM networks via Keras/TensorFlow) to forecast deterioration in  credit.

The motivation: Accurate delinquency forecasts are critical for credit risk management, ABS pricing, and provisioning for future losses. This project explores incorporating different indicators via different models (SARIMAX, LSTM's, etc.) to yield better predictive performance.
